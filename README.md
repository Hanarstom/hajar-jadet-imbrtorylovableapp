Build a minimal working Social Media Platform named "Neon" linked to my connected Supabase database. Strict budget optimization for low credits:

1. Real Auth: Enable Supabase email signup/login. Create a real 'profiles' table for actual users (stores names, profile pics, total views, followed count).

2. Profile Metrics: Display the "Followers Count" and "Total Video/Reels Views Count" clearly inside the user profile layout right under the user's name.

3. Live Post Feed: Create a global 'posts' table. Users can publish text, hashtags, and YouTube/Shorts links. Anyone can delete their own posts. Newest posts must appear at the top.

4. Video Blur Lock: Extract YouTube embed ID. Apply CSS blur on the video container. Overlay a "Play Video" button that redirects via a direct link handler (placeholder for Adsterra Direct Link).

5. Social Features: Dedicated search bar to query real users, simple live follow/unfollow system, and live text comments.

6. Adsterra Banners: In-feed HTML placeholders labeled "Sponsored Content" for banner code injections.

7. Monetization Stats: Simple dashboard fetching real profile data to track: 700 followers, 400 watch hours, 500k views. Show locked Binance/PayPal withdraw button.

Generate complete clean backend schemas and basic frontend in ONE fast step.
